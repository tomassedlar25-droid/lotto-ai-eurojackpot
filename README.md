# LOTTO AI 2.3 – HYBRID X

Přidána strategie HYBRID X (hlavní čísla a volitelně euročísla). Používá předem fixovanou kombinaci pořadí Momentum, Bayes, Decay, Hot15, Reversal a Gap pro hlavní čísla; pro euročísla Bayes, Decay, Momentum, Hot15 a Gap. Nezaručuje vyšší šanci výhry.

Na GitHub nahraj 7 souborů aktualizace do kořene repozitáře. Ponech historii `data/eurojackpot.csv` a ikony. V Generátoru vyber HYBRID X, případně pro euročísla režim samostatného modelu HYBRID X. Pro férové posouzení porovnávej se stejně nastaveným Ensemble a nepoužívej 500 již prozkoumaných losování jako důkaz úspěchu.
